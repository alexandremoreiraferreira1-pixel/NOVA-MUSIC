# NOVA-MUSIC
🎧 **NOVA MUSIC** é uma plataforma de streaming de música inspirada no Spotify e YouTube Music. Com visual moderno e intuitivo, permitirá pesquisar e reproduzir músicas, criar playlists, favoritar faixas e descobrir novos artistas. Desenvolvido com HTML, CSS e JavaScript.  **NOVA MUSIC — Sua música, seu mundo.**
